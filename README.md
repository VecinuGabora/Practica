# Flux Comandă Local - Food Ordering System

Aplicație web frontend pentru un sistem de comandă online, dezvoltată utilizând  HTML, CSS , JavaScript și Vite.

## Setup și Rulare
Execută următoarele comenzi în terminalul din directorul proiectului:

1. `npm install` — Instalează pachetele și dependențele necesare.
2. `npm run dev` — Pornește serverul local de dezvoltare (Vite).
3. Deschiderea în browser adresa locală indicată în terminal.
